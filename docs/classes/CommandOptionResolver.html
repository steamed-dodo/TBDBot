    Class CommandOptionResolver

    A discord.js-style typed accessor over the options of an interaction.

    The resolver is created per interaction and is cheap: it holds the raw options array and performs linear lookups by name. No schema lookup is needed at runtime — the type check is against the runtime option's own type field, which is what makes the mismatch check meaningful.
