    Class Wizard

    A branching, choice-driven wizard.

    A wizard captures an answer per step, follows the next pointers of its steps, and can go back — which clears the answers that were abandoned on the way. It is a different class from Menu rather than one class with a mode flag: the difference is in the state transitions, and nothing else.
