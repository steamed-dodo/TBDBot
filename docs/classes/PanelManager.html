    Class PanelManager

    Owns the lifecycle of persistent widgets.

    The manager keeps the store, the registry of widget factories, and the set of live widgets in sync. On boot it restores the widgets, re-binding their messages so that they keep routing correctly.

    The manager works with any widget that exposes a type, a serialize() hook and a restore() hook, so a persistent menu is restored exactly like a panel is.
