    Class Panel<S>Abstract

    Base class for a persistent Discord message controlled by custom components.

    A panel is a widget with a long lifetime: it has no timeout and is not tied to a collector. A PanelManager routes interactions by routing id, which allows panels to keep working after the bot restarts.

    The panel holds only identifiers — never a message object — because the message may be edited or deleted by another client and the framework deliberately keeps no cache.
