    Interface FrameworkGateway

    A gateway implementation usable by the framework.

    This is @discordjs/core's Gateway interface plus the optional connect/destroy hooks the framework uses for its lifecycle. The production implementation is @discordjs/ws's WebSocketManager; tests can supply their own.
